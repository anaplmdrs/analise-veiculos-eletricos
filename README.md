# 🚗🔋 Análise de Veículos Elétricos – Washington (EUA)
📌 Descrição

Este projeto realiza uma análise exploratória de dados (EDA) sobre veículos elétricos registrados no estado de Washington, nos Estados Unidos.
O objetivo é identificar padrões de adoção, tendências ao longo do tempo, autonomia média e principais fabricantes.

📊 Conjunto de Dados

Fonte: Washington State Department of Licensing
Principais colunas:

Model Year → Ano do veículo
Make → Montadora
Model → Modelo
Electric Range → Autonomia elétrica estimada (em milhas)
County → Condado de registro

🛠️ Tecnologias Utilizadas

Python 3
Pandas → manipulação de dados
Matplotlib & Seaborn → visualizações
Jupyter Notebook → organização das análises

🔎 Etapas Realizadas

Carregamento e inspeção dos dados
Limpeza e padronização

Análise exploratória (EDA):

Distribuição de veículos por tipo e condado
Autonomia média por ano/modelo
Evolução de registros ao longo dos anos
Montadoras e modelos mais comuns
Visualizações gráficas para apoiar insights

📈 Resultados e Insights

O número de veículos elétricos vem crescendo ao longo dos anos.
Algumas montadoras, como Tesla, concentram grande parte dos registros.
A autonomia média dos veículos aumentou significativamente nos últimos anos, no entanto, apesar desse marca importante, os carros mais vendidos não possuem tal característica
